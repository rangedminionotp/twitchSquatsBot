      Optional donation integrations

      Bits are configured above. Streamlabs and StreamElements tips can each be enabled independently. Tokens are stored encrypted, never returned to this page. Do not enable both for the same donation feed: providers use different event IDs, so cross-provider duplicates cannot be detected.

      Privacy and account data

      Stored: Twitch identity, encrypted integration tokens, counter totals, queue and deduplication records. Camera video is not stored. Stop Twitch listening and wait for cleanup before deletion.
